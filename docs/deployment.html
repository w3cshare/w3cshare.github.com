部署方案 ​

环境要求 ​

开发环境 ​

  • Node.js >= 18.0.0
  • PNPM >= 8.0.0
  • Docker >= 24.0.0
  • Docker Compose >= 2.0.0

生产环境 ​

  • Kubernetes >= 1.24
  • Helm >= 3.0
  • Nginx >= 1.20
  • MongoDB >= 6.0
  • PostgreSQL >= 15.0
  • Redis >= 7.0
  • RabbitMQ >= 3.0
