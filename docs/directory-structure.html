目录命名规范 ​

  1. 应用目录

    • 使用小写字母
    • 多个单词用连字符分隔
    • 例如：vue-app, react-app

  2. 包目录

    • 使用小写字母
    • 多个单词用连字符分隔
    • 例如：ui-components, utils

  3. 源代码目录

    • 使用小写字母
    • 多个单词用连字符分隔
    • 例如：src, components

  4. 配置文件

    • 使用小写字母
    • 以点开头
    • 例如：.gitignore, .eslintrc

文件命名规范 ​

  1. 组件文件

    • 使用 PascalCase
    • 例如：UserProfile.vue, Button.tsx

  2. 工具文件

    • 使用 camelCase
    • 例如：httpClient.ts, utils.ts

  3. 样式文件

    • 使用 kebab-case
    • 例如：main-style.css, theme-variables.scss

  4. 配置文件

    • 使用小写字母
    • 例如：package.json, tsconfig.json
