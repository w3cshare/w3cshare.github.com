# eslint-plugin-smart 快速开始

::: tip 插件介绍
eslint-plugin-smart 是一个为公司内部项目设计的 ESLint 规则集合，提供了针对 JavaScript、TypeScript、React、Vue 和 Node.js 等多种技术栈的全面规则配置。插件采用模块化设计，便于维护和扩展。
:::

## 快速开始

### 安装

根据您使用的包管理器选择相应的安装命令：

::: code-group

```bash [pnpm]
# 使用 pnpm (推荐)
pnpm add -D eslint eslint-plugin-smart
```

```bash [npm]
# 使用 npm
npm install --save-dev eslint eslint-plugin-smart
```

```bash [yarn]
# 使用 yarn
yarn add --dev eslint eslint-plugin-smart
```

:::

### 配置文件命名规范

根据项目使用的模块系统，ESLint 配置文件应遵循以下命名规则：

- **CommonJS 项目**：使用 `eslint.config.cjs`
- **ESModule 项目**：使用 `eslint.config.mjs`
- **传统配置**：使用 `.eslintrc.js` 或 `.eslintrc.cjs`

::: warning 注意
确保配置文件扩展名与项目的模块系统匹配，以避免加载错误。
:::

### 基础配置

::: code-group

```js [ESLint v9+ (ESM)]
// eslint.config.mjs
import eslintPlugin from 'eslint-plugin-smart'

// 注意：配置是一个数组，需要展开
export default [
  ...eslintPlugin.configs.recommended,
  {
    // 这里可以添加自定义规则
  },
]
```

```js [ESLint v9+ (CJS)]
// eslint.config.cjs
const eslintPlugin = require('eslint-plugin-smart')

// 注意：配置是一个数组，需要展开
module.exports = [
  ...eslintPlugin.configs.recommended,
  {
    // 这里可以添加自定义规则
  },
]
```

```js [ESLint v8 及以下]
// .eslintrc.js 或 .eslintrc.cjs
module.exports = {
  extends: ['plugin:smart/recommended'],
}
```

:::

#### NestJS 项目

::: code-group

```js [ESLint v9+]
// eslint.config.mjs
import js from '@eslint/js'
import tseslint from 'typescript-eslint'
import eslintPlugin from 'eslint-plugin-smart'

// 获取typescript-eslint推荐配置
const typescriptConfigs = tseslint.configs.recommended

// 创建自定义配置
const customConfig = {
  files: ['**/*.js', '**/*.ts', '**/*.jsx', '**/*.tsx', 'src/**/*.ts'],
  ignores: ['**/node_modules/**', '**/dist/**'],
  plugins: {
    smart: eslintPlugin,
  },
  languageOptions: {
    parser: tseslint.parser,
    parserOptions: {
      ecmaVersion: 'latest',
      sourceType: 'module',
      project: './tsconfig.json',
      experimentalDecorators: true,
      emitDecoratorMetadata: true,
    },
    globals: {
      node: true,
      jest: true,
    },
  },
  rules: {
    // 明确禁用有冲突的规则
    '@typescript-eslint/no-empty-function': 'off',

    // 允许下划线开头的未使用变量
    '@typescript-eslint/no-unused-vars': [
      'error',
      {
        argsIgnorePattern: '^_',
        varsIgnorePattern: '^_',
        caughtErrorsIgnorePattern: '^_',
      },
    ],
  },
}

// 导出配置
export default [
  // 导入eslint-plugin-smart推荐配置
  { ...eslintPlugin.configs.recommended },
  // 引入js的推荐配置
  js.configs.recommended,
  // 添加typescript-eslint推荐配置
  ...typescriptConfigs,
  // 自定义配置（优先级最高，会覆盖之前的配置）
  customConfig,
]
```

```js [ESLint v8 及以下]
// .eslintrc.js
module.exports = {
  extends: ['plugin:smart/nestjs'],
}
```

:::

::: warning 注意文件匹配模式
在ESLint v9+的扁平配置中，需要特别注意`files`和`ignores`属性的配置：

1. **指定要检查的文件模式**：确保明确列出所有需要检查的文件类型，包括项目特定的路径模式（如`src/**/*.ts`）
2. **指定要忽略的文件模式**：明确列出不需要检查的目录或文件类型
3. **常见问题排查**：如果运行ESLint时出现"all files are ignored"错误，通常是因为文件模式配置不正确
   :::

## 规则说明

eslint-plugin-smart 采用模块化设计，提供了多种预设配置，根据项目类型可选择不同的配置集合：

| 预设配置            | 说明                 | 适用场景                   |
| ------------------- | -------------------- | -------------------------- |
| `smart/base`        | 基础 JavaScript 配置 | 适用于所有 JavaScript 项目 |
| `smart/typescript`  | TypeScript 配置      | 适用于 TypeScript 项目     |
| `smart/react`       | React 配置           | 适用于 React 项目          |
| `smart/vue`         | Vue 配置             | 适用于 Vue 项目            |
| `smart/nestjs`      | NestJS 配置          | 适用于 NestJS 后端项目     |
| `smart/recommended` | 全栈推荐配置         | 适用于全栈开发项目         |

### 模块化设计

eslint-plugin-smart 将各技术栈的规则集分离出来，便于维护和扩展：

```js
// 分别导出各个技术栈的规则集
export const javascriptRules = {
  /* JavaScript 规则 */
}
export const typescriptRules = {
  /* TypeScript 规则 */
}
export const reactRules = {
  /* React 规则 */
}
export const vueRules = {
  /* Vue 规则 */
}
export const nodejsRules = {
  /* Node.js 规则 */
}

// 组合规则集
export default {
  base: javascriptRules,
  typescript: { ...javascriptRules, ...typescriptRules },
  react: { ...javascriptRules, ...reactRules },
  vue: { ...javascriptRules, ...vueRules },
  nodejs: { ...javascriptRules, ...nodejsRules },
  recommended: {
    ...javascriptRules,
    ...typescriptRules,
    ...reactRules,
    ...vueRules,
    ...nodejsRules,
  },
}
```

## 自定义配置

你可以在项目中扩展基础配置并添加自定义规则：

::: code-group

```js [ESLint v9+]
// eslint.config.mjs
import eslintPlugin from 'eslint-plugin-smart'

export default [
  ...eslintPlugin.configs.typescript, // 使用 TypeScript 预设
  {
    // 覆盖或添加自定义规则
    rules: {
      // 关闭部分规则
      '@typescript-eslint/no-explicit-any': 'off',
      'no-console': 'off',

      // 调整规则设置
      'max-len': ['warn', { code: 100, ignoreComments: true }],

      // 添加自定义规则
      'prefer-template': 'error',
    },
  },
]
```

```js [ESLint v8 及以下]
// .eslintrc.js
module.exports = {
  extends: ['plugin:smart/typescript'], // 使用 TypeScript 预设
  rules: {
    // 关闭部分规则
    '@typescript-eslint/no-explicit-any': 'off',
    'no-console': 'off',

    // 调整规则设置
    'max-len': ['warn', { code: 100, ignoreComments: true }],

    // 添加自定义规则
    'prefer-template': 'error',
  },
```

## 常见问题处理

### TypeScript版本兼容性

使用较新版本的TypeScript时，可能会出现以下警告：

```
WARNING: You are currently running a version of TypeScript which is not officially supported by @typescript-eslint/typescript-estree.
```

**解决方案：**

1. 降级TypeScript版本至兼容版本：

   ```bash
   pnpm add -D typescript@~5.5.0
   ```

2. 忽略此警告（如果功能正常）：
   在CI/CD流程或特定情况下，可以暂时忽略此警告。

### NestJS装饰器解析错误

如果在NestJS项目中出现如下解析错误：

```
Parsing error: Unexpected character '@'
```

**解决方案：**

确保在ESLint配置的parserOptions中添加对装饰器的支持：

```js
languageOptions: {
  parserOptions: {
    experimentalDecorators: true,
    emitDecoratorMetadata: true,
  }
}
```

### 未使用变量错误

对于有意不使用的变量（如接口实现、类型定义或临时禁用的代码），可能会出现未使用变量的警告。

**解决方案：**

1. 使用下划线前缀命名变量（推荐）：

   ```typescript
   const _unusedVar = 'something' // ESLint将忽略以下划线开头的变量
   ```

2. 在ESLint配置中添加规则允许下划线前缀变量：
   ```js
   '@typescript-eslint/no-unused-vars': ['error', {
     argsIgnorePattern: '^_',
     varsIgnorePattern: '^_',
     caughtErrorsIgnorePattern: '^_'
   }],
   ```

## ESLint v9 配置变更说明

ESLint v9 引入了扁平配置系统，相较于之前的配置方式有一些重要变化。本节介绍一些常见的配置变更点。

### 环境变量配置

在 ESLint v9 中，不再使用 `env` 字段来设置环境变量，而是通过 `languageOptions.globals` 字段：

```js
// ESLint v8 及以下配置方式
module.exports = {
  env: {
    browser: true,
    node: true,
    jest: true,
  },
}

// ESLint v9 配置方式
export default [
  {
    languageOptions: {
      globals: {
        browser: true,
        node: true,
        jest: true,
      },
    },
  },
]
```

::: warning 注意
如果使用 eslint-plugin-smart v1.2.1 及以上版本，已自动处理此变更，无需手动调整。
:::

# JSON排序功能

eslint-plugin-smart现在支持对JSON文件进行格式化和自动排序，提高JSON文件的可读性和一致性。特别适用于管理`package.json`文件，确保依赖项和配置按照一致的顺序排列。

## 功能特点

- 自动对JSON对象的键进行排序
- 自动对JSON数组内的值进行排序
- 根据文件类型应用特定的排序规则（如`package.json`的字段顺序）
- 支持JSONC（带注释的JSON）和JSON5格式
- 与其他格式化工具（如Prettier）无缝集成

## 安装使用

在项目中安装eslint-plugin-smart：

```bash
# 使用npm
npm install eslint-plugin-smart --save-dev

# 使用yarn
yarn add eslint-plugin-smart --dev

# 使用pnpm
pnpm add eslint-plugin-smart -D
```

## 配置方法

### ESLint v9（扁平配置）

在`eslint.config.mjs`中添加JSON排序配置：

```javascript
import smart from 'eslint-plugin-smart'

export default [
  // 基础配置
  ...smart.configs.base,

  // JSON配置（用于JSON文件排序）
  ...smart.configs.json,
]
```

### ESLint v8及以下（传统配置）

在`.eslintrc.js`或`.eslintrc.cjs`中：

```javascript
module.exports = {
  extends: [
    'plugin:smart/base',
    'plugin:smart/json', // 添加JSON排序支持
  ],
}
```

## 规则详解

JSON排序功能主要包含以下规则：

### 基础规则

| 规则名称                    | 描述               | 默认值 |
| --------------------------- | ------------------ | ------ |
| jsonc/array-bracket-spacing | 数组括号前后的空格 | never  |
| jsonc/comma-dangle          | 末尾逗号           | never  |
| jsonc/comma-style           | 逗号风格           | last   |
| jsonc/indent                | 缩进               | 2      |
| jsonc/no-comments           | 是否允许注释       | off    |
| jsonc/object-curly-spacing  | 对象花括号内的空格 | always |
| jsonc/quote-props           | 属性名引号         | always |
| jsonc/quotes                | 引号类型           | double |

### 排序规则

#### jsonc/sort-keys

按照指定的顺序或字母顺序排序对象的键：

```json
// 排序前
{
  "version": "1.0.0",
  "name": "my-package",
  "description": "描述"
}

// 排序后
{
  "name": "my-package",
  "version": "1.0.0",
  "description": "描述"
}
```

对于`package.json`文件，我们应用了特定的字段顺序：

1. 首先是基本信息（name, version, description等）
2. 然后是构建相关字段（main, module, types等）
3. 接着是依赖项（dependencies, devDependencies等）
4. 最后是工具配置（husky, lint-staged等）

#### jsonc/sort-array-values

按照字母顺序排序数组中的值：

```json
// 排序前
{
  "keywords": ["react", "eslint", "typescript", "angular"]
}

// 排序后
{
  "keywords": ["angular", "eslint", "react", "typescript"]
}
```

## 使用场景

### package.json 排序

自动对package.json文件的内容进行排序，确保重要字段按照约定顺序排列，依赖项按字母排序：

```bash
eslint --fix package.json
```

### 批量处理项目中的所有JSON文件

```bash
eslint --fix "**/*.json"
```

### CI/CD 流程集成

可以在持续集成流程中添加JSON检查和自动排序：

```yaml
# GitHub Actions 示例
jobs:
  lint:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3
      - uses: actions/setup-node@v3
      - run: npm install
      - run: npm run lint:json
```

## 自定义配置

如果需要自定义JSON排序规则，可以在项目的ESLint配置中覆盖默认设置：

```javascript
// eslint.config.mjs (ESLint v9)
export default [
  // 其他配置...
  {
    files: ['**/*.json'],
    rules: {
      // 自定义排序顺序
      'jsonc/sort-keys': [
        'error',
        {
          pathPattern: '^$',
          order: ['自定义', '排序', '顺序'],
        },
      ],
    },
  },
]
```

## 注意事项

1. 排序功能默认不会更改JSON的内容，只会调整键和数组的顺序
2. 对于特殊的JSON结构，可能需要自定义排序规则
3. 该功能可能与某些自动生成的JSON文件冲突，可以在`.eslintignore`中排除特定文件

## 常见问题

### 如何排除特定JSON文件？

```
// .eslintignore
generated-schema.json
**/locales/*.json
```

### 如何只对package.json应用特定规则？

可以使用文件匹配模式：

```javascript
// eslint.config.mjs
export default [
  // 基础JSON规则
  ...smart.configs.json,

  // package.json特定规则
  {
    files: ['**/package.json'],
    rules: {
      // 自定义package.json特定规则
    },
  },
]
```

## 最佳实践

1. 在保存时自动修复JSON文件（需要编辑器支持）
2. 在提交前使用husky和lint-staged检查和排序JSON文件
3. 在团队中统一使用相同的JSON排序规则
4. 结合Prettier一起使用，确保格式一致性
