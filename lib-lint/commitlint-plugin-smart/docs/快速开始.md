# 快速开始

## 安装

```bash
# 使用 npm
npm install --save-dev commitlint-plugin-smart @commitlint/cli

# 使用 yarn
yarn add -D commitlint-plugin-smart @commitlint/cli

# 使用 pnpm
pnpm add -D commitlint-plugin-smart @commitlint/cli
```

## 基础配置

### 步骤 1: 配置 commitlint

在项目根目录创建 `.commitlintrc.js` 或 `.commitlintrc.mjs` 文件：

```js
// .commitlintrc.js
import commitlintPluginSmart from 'commitlint-plugin-smart'

export default commitlintPluginSmart.defineConfig()
```

### 步骤 2: 配置 package.json

添加以下配置到 `package.json`：

```json
{
  "scripts": {
    "commit": "git-cz"
  },
  "config": {
    "commitizen": {
      "path": "node_modules/commitlint-plugin-smart"
    }
  }
}
```

### 步骤 3: 配置 Husky

确保提交前验证 commit 信息：

```bash
# 安装 husky
npm install --save-dev husky

# 初始化 husky
npx husky install

# 添加 commit-msg 钩子
npx husky add .husky/commit-msg 'npx --no -- commitlint --edit $1'
```

## 使用方法

安装配置完成后，可以通过以下方式使用：

```bash
# 使用脚本命令
npm run commit

# 或直接使用 npx
npx git-cz
```

然后按照交互式提示完成提交信息的填写：

1. 选择提交类型（如 feat、fix、docs 等）
2. 选择作用域（可选）
3. 填写简短的提交描述
4. 填写详细的变更描述（可选）
5. 是否有破坏性变更（可选）
6. 是否关联 Issue（可选）

## 提交示例

以下是一些常见的提交示例：

- 添加新功能：`✨ feat(components): 添加用户登录组件`
- 修复 Bug：`🐛 fix(utils): 修复日期格式化函数的时区问题`
- 更新文档：`📝 docs: 更新安装说明文档`
- 代码重构：`🎨 refactor(core): 重构数据处理逻辑`
- 性能优化：`👌 perf(api): 优化查询性能`
- 添加测试：`✅ test: 添加用户服务的单元测试`
