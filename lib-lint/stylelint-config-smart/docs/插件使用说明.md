# Stylelint 智能配置使用说明

## 简介

`stylelint-config-smart` 是一个企业级的 Stylelint 共享配置，提供了现代化且全面的 CSS 代码规范。适用于各种前端技术栈和框架，完美支持 React、Vue 和纯 TypeScript 项目。

## 特性

- 完整支持 CSS、SCSS、Less 和 Vue 单文件组件
- 智能的属性排序规则
- BEM 命名规范检查
- 与 Prettier 完美集成
- 支持现代 CSS 特性
- 针对不同框架的专门优化

## 快速开始

### 1. 安装

使用你喜欢的包管理器安装：

```bash
# pnpm (推荐)
pnpm add -D stylelint stylelint-config-smart

# npm
npm install --save-dev stylelint stylelint-config-smart

# yarn
yarn add -D stylelint stylelint-config-smart
```

### 2. 配置

在项目根目录创建 `stylelint.config.cjs` 文件：

```js
const config = require('stylelint-config-smart')

module.exports = config.default
```

### 3. 使用

添加 npm scripts 到 `package.json`：

```json
{
  "scripts": {
    "lint:style": "stylelint \"**/*.{css,scss,less,vue}\" --fix"
  }
}
```

然后运行：

```bash
pnpm run lint:style
```

## 规则说明

### 核心规则

1. 选择器规范
   - 类名使用 kebab-case 命名
   - 限制选择器嵌套深度（最大5层）
   - 限制复合选择器数量（最大5个）
   - ID 选择器限制使用（每个规则最多1个）

2. 属性规范
   - 禁止重复属性声明
   - 使用简写属性
   - 属性值去重
   - 属性顺序自动排序

3. 颜色规范
   - 使用十六进制或 RGB/HSL
   - 禁止使用命名颜色（如 red、blue）
   - 使用简短十六进制值（#fff 而非 #ffffff）
   - 使用现代颜色函数语法

### 特定文件类型规则

#### Vue 单文件组件

```vue
<style scoped>
.component {
  /* ✓ 支持嵌套语法 */
  &:deep(.child) {
    color: #f00;  /* ✗ 应使用 #ff0000 或 rgb */
  }
}
</style>
```

#### SCSS

```scss
// ✓ 变量命名规范
$primary-color: #1890ff;

// ✗ 重复的 mixin 定义
@mixin border-radius {
  border-radius: 4px;
}

.container {
  @include border-radius;
  color: red;  // ✗ 应使用 #ff0000
}
```

#### Less

```less
// ✓ 变量命名规范
@primary-color: #1890ff;

.container {
  // ✗ 冗余的嵌套选择器
  & > .item {
    color: red;  // ✗ 应使用 #ff0000
  }
}
```

## 常见问题

### 1. 如何处理误报？

如果某些规则在特定场景下不适用，可以使用注释暂时禁用：

```css
/* stylelint-disable color-named */
.error-message {
  color: red;
}
/* stylelint-enable color-named */
```

### 2. 与其他工具集成

#### VS Code

1. 安装 Stylelint 插件
2. 添加设置：

```json
{
  "stylelint.validate": ["css", "scss", "less", "vue"],
  "editor.codeActionsOnSave": {
    "source.fixAll.stylelint": true
  }
}
```

#### Git Hooks

使用 husky 和 lint-staged：

```json
{
  "lint-staged": {
    "*.{css,scss,less,vue}": [
      "stylelint --fix"
    ]
  }
}
```

## 错误代码示例与修复

以下是一些常见的错误及其修复方法：

### 1. 命名颜色

```css
/* ✗ 错误 */
.button {
  color: red;
  background: blue;
}

/* ✓ 正确 */
.button {
  color: #ff0000;
  background: #0000ff;
}
```

### 2. 媒体查询格式

```css
/* ✗ 错误 */
@media (width >= 768px) {
  .container {
    width: 750px;
  }
}

/* ✓ 正确 */
@media (min-width: 768px) {
  .container {
    width: 750px;
  }
}
```

### 3. 重复属性

```css
/* ✗ 错误 */
.element {
  margin: 10px;
  margin-top: 20px;
}

/* ✓ 正确 */
.element {
  margin: 20px 10px 10px;
}
```
