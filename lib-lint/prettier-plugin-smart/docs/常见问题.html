常见问题 ​

本文档汇总了使用 prettier-plugin-smarts 插件时可能遇到的常见问题及其解决方案。

警告信息 "Ignored unknown option" ​

问题描述 ​

在使用 prettier-plugin-smarts 插件时，特别是当你配置了 sortJsonKeys 和 importOrder 等自定义选项时，你可能会在运行 Prettier 命令时看到类似以下的警告：

[warn] Ignored unknown option { sortJsonKeys: true }.
[warn] Ignored unknown option { importOrder: "^react,^@/,^[./]" }.
1
2

例如，在项目中运行格式化命令时：

bash
pnpm run format

> grpc-gateway@0.0.1 format /Users/ww/Desktop/FullStack/micro-service/grpc-gateway
> prettier --write "src/**/*.ts" "test/**/*.ts"

[warn] Ignored unknown option { sortJsonKeys: true }.
[warn] Ignored unknown option { importOrder: "^react,^@/,^[./]" }.
src/app.controller.spec.ts 68ms (unchanged)
[warn] Ignored unknown option { sortJsonKeys: true }.
[warn] Ignored unknown option { importOrder: "^react,^@/,^[./]" }.
src/app.controller.ts 14ms (unchanged)

原因 ​

这些警告是由于 Prettier 核心不识别 prettier-plugin-smarts 插件的自定义选项所导致的。Prettier 检测到配置文件中有它不认识的选项时会发出警告，但这不影响插件的正常工作。

解决方法 ​

  1. 安全忽略：这些警告不会影响格式化结果，可以安全忽略。

  2. 使用 JavaScript 配置文件：将 .prettierrc JSON 文件转换为 .prettierrc.js JavaScript 文件格式：

    js
    // .prettierrc.js
/** @type {import("prettier").Config} */
const config = {
  // 标准配置
  printWidth: 100,
  tabWidth: 2,
  singleQuote: true,
  trailingComma: 'es5',

  // 插件配置
  plugins: ['prettier-plugin-smarts'],
  sortJsonKeys: true,
  importOrder: '^react,^@/,^[./]',
}

module.exports = config

    bash
    prettier --write --no-error-on-unmatched-pattern "src/**/*.ts"

  4. 使用编辑器插件：通过 VS Code 的 Prettier 插件格式化代码时，通常不会显示这些警告。

插件无法正确加载 ​

问题描述 ​

插件安装后无法正常工作，格式化时没有应用自定义规则。

解决方法 ​

  1. 检查插件安装：确保插件已正确安装：

    bash
    # pnpm
pnpm list prettier-plugin-smarts

# npm
npm list prettier-plugin-smarts

    js
    // .prettierrc.js

  plugins: ['prettier-plugin-smarts'],
  // 其他配置
}

    "prettier": "^3.0.0",
    "prettier-plugin-smarts": "^1.0.0"

插件与其他插件冲突 ​

问题描述 ​

当同时使用多个 Prettier 插件时，可能会出现冲突，导致某些插件的功能无法正常工作。

解决方法 ​

Prettier 插件的加载顺序会影响其行为。确保 prettier-plugin-smarts 在插件列表中的顺序是最后的：

js
// .prettierrc.js
module.exports = {
  plugins: [
    'prettier-plugin-tailwindcss', // 其他插件
    'prettier-plugin-organize-imports', // 其他插件
    'prettier-plugin-smarts', // 放在最后
  ],
}

在 Mono Repo 中的配置问题 ​

问题描述 ​

在 Lerna + Nx + pnpm + Workspace 的单体（mono）项目中，子项目的 Prettier 配置无法正确继承根配置。

解决方法 ​

  1. 根目录配置：在根目录创建基础配置：

    js
    // 根目录 .prettierrc.js
/** @type {import("prettier").Config} */
const config = {
  printWidth: 100,
  tabWidth: 2,
  singleQuote: true,
  plugins: ['prettier-plugin-smarts'],
  sortJsonKeys: true,
  importOrder: '^react,^@/,^[./]',
}

module.exports = config

const config = require('../../.prettierrc.js')

module.exports = {
  ...config,
  // 子项目特定配置
  importOrder: '^@nestjs/,^@/modules/,^@/,^[./]',

格式化缓慢问题 ​

问题描述 ​

在大型项目中使用插件可能会导致格式化过程变慢。

解决方法 ​

  1. 限制格式化范围：仅格式化修改的文件，而不是整个项目：

    bash
    # 仅格式化修改的文件
git diff --name-only | grep -E '\.(js|ts|tsx|vue|json)$' | xargs prettier --write
    1
    2

  2. 使用缓存：配置 Prettier 使用缓存：

    js
    // .prettierrc.js
module.exports = {
  // 启用缓存（Prettier v3.0+）
  cache: true,
  // 其他配置
}
    1
    2
    3
    4
    5
    6

  3. 优化导入规则：简化 importOrder 配置，减少复杂度。

调试技巧 ​

如果你遇到了其他问题，可以使用以下技巧进行调试：

  1. 检查配置：使用 Prettier 的调试命令查看实际使用的配置：

    bash
    npx prettier --find-config-path file.js
npx prettier --config-precedence file.js
    1
    2

  2. 检查格式化问题：使用调试检查命令：

    bash
    npx prettier --debug-check your-file.js
    1

  3. 查看插件列表：确认已加载的插件：

    bash
    npx prettier --debug-plugins
    1

如有其他问题，请查看 GitHub 仓库 提交 issue 或参考 Prettier 官方文档。
