# Prettier 智能插件

prettier-plugin-smart 是一个专为公司内部项目设计的 Prettier 插件，提供了一系列智能的代码格式化功能。特别适用于基于 React、Vue 和 TypeScript 的项目。

## 为什么需要统一的代码格式化？

在多人协作的项目中，统一的代码格式化规范能够带来以下好处：

1. **提高代码可读性**：统一的格式使团队成员更容易理解彼此的代码
2. **减少合并冲突**：相同的格式化规则可以减少因格式差异导致的版本控制冲突
3. **提升代码质量**：一致的风格有助于发现潜在问题
4. **节省时间**：自动化的格式化减少了手动调整的时间
5. **简化代码审查**：审查者可以专注于代码逻辑而非格式

## 插件功能

prettier-plugin-smart 提供了以下核心功能：

### 1. JSON 智能排序

自动对 JSON 文件中的键进行排序，包括：

- **package.json 专用排序**：遵循 NPM 包管理标准，确保关键字段（如 name、version、scripts）始终位于文件顶部
- **ESLint 配置排序**：优化 ESLint 配置文件的字段顺序，提高可读性
- **通用 JSON 排序**：按字母顺序排列其他 JSON 文件的键

### 2. Import 语句组织

自动组织和排序 JavaScript/TypeScript 文件中的 import 语句：

- **分组**：根据配置将导入分为不同组（如第三方库、内部模块、相对路径）
- **排序**：在每个组内按字母顺序排序
- **空行分隔**：在不同组之间添加空行，提高可读性

### 3. Vue 文件格式化增强

为 Vue 单文件组件提供增强的格式化功能：

- **标签缩进控制**：自定义 `<script>` 和 `<style>` 标签内容的缩进
- **属性排序**：对模板中的属性进行排序
- **CSS 规则排序**：按照推荐的顺序排列 CSS 属性

## 安装指南

### 依赖项

- Node.js >= 14
- Prettier >= 2.0.0

### 安装步骤

```bash
# 使用 pnpm 安装（推荐）
pnpm add -D prettier prettier-plugin-smart

# 或使用 npm
npm install --save-dev prettier prettier-plugin-smart

# 或使用 yarn
yarn add -D prettier prettier-plugin-smart
```

## 基础配置

在项目根目录创建 `.prettierrc.js` 文件：

```js
module.exports = {
  // 基础 Prettier 配置
  printWidth: 100,
  tabWidth: 2,
  useTabs: false,
  semi: true,
  singleQuote: true,
  trailingComma: 'es5',
  bracketSpacing: true,
  arrowParens: 'avoid',

  // prettier-plugin-smart 专有配置
  sortJsonKeys: true,
  importOrder: '^react,^@/,^[./]',
  vueIndentScriptAndStyle: true,
}
```

## 配置详解

### sortJsonKeys

控制是否对 JSON 文件的键进行排序。

```js
module.exports = {
  // 启用 JSON 键排序（默认）
  sortJsonKeys: true,

  // 禁用 JSON 键排序
  // sortJsonKeys: false
}
```

应用示例：

原始 JSON：

```json
{
  "version": "1.0.0",
  "scripts": {
    "start": "node index.js",
    "build": "webpack"
  },
  "name": "my-project"
}
```

格式化后：

```json
{
  "name": "my-project",
  "version": "1.0.0",
  "scripts": {
    "build": "webpack",
    "start": "node index.js"
  }
}
```

### importOrder

控制 import 语句的排序和分组规则。格式为以逗号分隔的正则表达式字符串，用于匹配导入路径。

```js
module.exports = {
  // React 项目推荐
  importOrder: '^react,^@/components/,^@/hooks/,^@/utils/,^[./]',

  // Vue 项目推荐
  // importOrder: '^vue,^@/components/,^@/composables/,^@/utils/,^[./]',

  // NestJS 项目推荐
  // importOrder: '^@nestjs/,^@/modules/,^@/services/,^@/dto/,^[./]'
}
```

应用示例：

原始代码：

```js
import './styles.css'
import { useState } from 'react'
import { Button } from '@/components/ui'
import React from 'react'
import { useAuth } from '@/hooks'
import { formatDate } from '@/utils'
```

格式化后：

```js
import React from 'react'
import { useState } from 'react'

import { Button } from '@/components/ui'
import { useAuth } from '@/hooks'
import { formatDate } from '@/utils'

import './styles.css'
```

### vueIndentScriptAndStyle

控制 Vue 单文件组件中 `<script>` 和 `<style>` 标签内容的缩进。

```js
module.exports = {
  // 启用标签内容缩进（默认）
  vueIndentScriptAndStyle: true,

  // 禁用标签内容缩进
  // vueIndentScriptAndStyle: false
}
```

## 与构建工具集成

### 与 Webpack 集成

使用 `prettier-webpack-plugin`：

```js
// webpack.config.js
const PrettierPlugin = require('prettier-webpack-plugin')

module.exports = {
  // ...其他配置
  plugins: [
    new PrettierPlugin({
      extensions: ['.js', '.jsx', '.ts', '.tsx', '.json', '.vue'],
      // prettier-plugin-smart 会自动加载
    }),
  ],
}
```

### 与 Vite 集成

使用 `vite-plugin-prettier`：

```js
// vite.config.js
import { defineConfig } from 'vite'
import prettier from 'vite-plugin-prettier'

export default defineConfig({
  plugins: [
    prettier({
      // prettier-plugin-smart 会自动加载
    }),
  ],
})
```

### 与 Ant Design 项目集成

对于使用 Ant Design 的项目，建议使用以下配置：

```js
// .prettierrc.js
module.exports = {
  printWidth: 100,
  singleQuote: true,
  importOrder: '^react,^antd/,^@ant-design/,^@/components/,^@/,^[./]',
  sortJsonKeys: true,
}
```

## 常见问题

### 1. 插件加载顺序问题

如果使用多个 Prettier 插件，加载顺序很重要。将 prettier-plugin-smart 放在插件列表的最后：

```js
// .prettierrc.js
module.exports = {
  plugins: [
    'prettier-plugin-packagejson',
    'prettier-plugin-organize-imports',
    'prettier-plugin-smart', // 放在最后
  ],
}
```

### 2. ESLint 集成问题

当与 ESLint 结合使用时，可能需要禁用一些重复的规则：

```js
// .eslintrc.js
module.exports = {
  extends: ['prettier'],
  rules: {
    'sort-imports': 'off', // 关闭 ESLint 的 import 排序，使用 prettier-plugin-smart
    'import/order': 'off',
  },
}
```

### 3. CI 集成

在 CI 环境中检查代码格式：

```yaml
# .github/workflows/prettier.yml
name: Prettier Check

on:
  pull_request:
    branches: [main, develop]

jobs:
  prettier:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3
      - uses: actions/setup-node@v3
        with:
          node-version: '16'
      - run: npm ci
      - run: npx prettier --check "**/*.{js,jsx,ts,tsx,json,vue}"
```

::: warning 关于警告信息
使用 JSON 格式的 `.prettierrc` 文件时，你可能会在运行 Prettier 命令时看到类似以下的警告：

```
[warn] Ignored unknown option { sortJsonKeys: true }.
[warn] Ignored unknown option { importOrder: "^react,^@/,^[./]" }.
```

这些警告是由于 Prettier 核心不识别这些自定义选项所导致的，但插件仍然会正常工作。这些警告不会影响格式化结果，可以安全忽略。

如果你希望避免这些警告，建议使用 `.prettierrc.js` 文件格式进行配置。
:::
