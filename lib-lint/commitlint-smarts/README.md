## 安装

::: code-group

```bash [pnpm]
pnpm add -D @commitlint/cli commitlint-smarts husky
```

```bash [npm]
npm install --save-dev @commitlint/cli commitlint-smarts husky
```

```bash [yarn]
yarn add -D @commitlint/cli commitlint-smarts husky
```
