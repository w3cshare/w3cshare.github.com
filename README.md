# 全栈开发文档

欢迎使用全栈开发文档！这是一个基于 Monorepo 架构的现代化全栈开发解决方案，集成了前端、后端、AI 和区块链等多种技术栈。

## 项目特点

- **微前端架构**：支持多种前端框架和开发模式
- **微服务架构**：灵活的后端服务架构
- **AI 集成**：内置 AI 能力
- **区块链支持**：以太坊相关功能
- **现代化工具链**：完整的开发工具支持
- **类型安全**：全栈 TypeScript 开发

## 快速开始

1. 克隆项目

```bash
git clone https://github.com/w3cshare/FullStack.git
cd FullStack
```

2. 安装依赖

```bash
pnpm install
```

3. 启动开发服务器

```bash
pnpm docs:dev
```
