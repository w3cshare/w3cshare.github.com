# 模型列表及对比

本文档列出了PaddleXOCR中各个模块支持的模型及其性能对比。这些模型针对不同的应用场景和设备环境进行了优化，用户可以根据实际需求选择合适的模型。

## 印章文本检测模块

印章文本检测模块通常会输出文本区域的多点边界框，这些边界框将作为输入传递给弯曲矫正和文本识别模块进行后续处理，识别出印章的文字内容。

|-----|--------------|-----------------|-----------------|----------------|-----|
| PP-OCRv4_server_seal_det | 98.21 | 84.341 | 2425.06 | 109 | PP-OCRv4的服务端印章文本检测模型，精度更高，适合在较好的服务器上部署 |
| PP-OCRv4_mobile_seal_det | 96.47 | 10.5878 | 131.813 | 4.6 | PP-OCRv4的移动端印章文本检测模型，效率更高，适合在端侧部署 |

*注：以上精度指标的评估集是自建的数据集，包含500张圆形印章图像。GPU 推理耗时基于 NVIDIA Tesla T4 机器，精度类型为 FP32， CPU 推理速度基于 Intel(R) Xeon(R) Gold 5117 CPU @ 2.00GHz，线程数为 8，精度类型为 FP32。*

表格结构识别是表格识别系统中的重要组成部分，能够将不可编辑表格图片转换为可编辑的表格形式（例如html）。

|-----|-----------|------------------|------------------|-----------------|-----|
| SLANet | 59.52 | 522.536 | 1845.37 | 6.9 | SLANet 是百度飞桨视觉团队自研的表格结构识别模型。该模型通过采用CPU友好型轻量级骨干网络PP-LCNet、高低层特征融合模块CSP-PAN、结构与位置信息对齐的特征解码模块SLA Head，大幅提升了表格结构识别的精度和推理速度。 |
| SLANet_plus | 63.69 | 522.536 | 1845.37 | 6.9 | SLANet_plus 是百度飞桨视觉团队自研的表格结构识别模型SLANet的增强版。相较于SLANet，SLANet_plus 对无线表、复杂表格的识别能力得到了大幅提升，并降低了模型对表格定位准确性的敏感度，即使表格定位出现偏移，也能够较准确地进行识别。 |

*注：以上精度指标测量自PaddleX 内部自建英文表格识别数据集。所有模型 GPU 推理耗时基于 NVIDIA Tesla T4 机器，精度类型为 FP32， CPU 推理速度基于 Intel(R) Xeon(R) Gold 5117 CPU @ 2.00GHz，线程数为8，精度类型为 FP32。*

## 模型适用场景对比

### 高精度需求场景

在对文档信息抽取精度要求极高的场景，如金融合同审核、法律文件分析等，推荐以下模型组合：

- 版面区域检测：RT-DETR-H系列模型
- 文本检测：PP-OCRv4_server_det
- 文本识别：PP-OCRv4_server_rec
- 表格结构识别：SLANet_plus
- 印章文本检测：PP-OCRv4_server_seal_det
- 文档图像方向分类：PP-LCNet_x1_0_doc_ori

虽然这些模型推理速度较慢或存储大小较大，但能保证较高的准确性。

### 移动端或低资源环境场景

对于移动端应用或资源受限的环境，如手机端文档处理APP、嵌入式设备等，推荐以下模型组合：

- 版面区域检测：PicoDet-S_layout_3cls或PicoDet-S_layout_17cls
- 文本检测：PP-OCRv4_mobile_det
- 文本识别：PP-OCRv4_mobile_rec
- 印章文本检测：PP-OCRv4_mobile_seal_det

这些模型在保证一定精度的前提下，能够满足移动端设备的性能和存储要求。

### 平衡性能场景

在对精度和速度都有一定要求的场景，如企业内部日常文档处理、小型办公系统等，推荐以下模型组合：

- 版面区域检测：PicoDet-L_layout_3cls或PicoDet-L_layout_17cls
- 文本检测：根据设备性能选择PP-OCRv4_mobile_det或PP-OCRv4_server_det
- 文本识别：根据精度需求选择PP-OCRv4_mobile_rec或PP-OCRv4_server_rec
- 表格结构识别：SLANet
- 印章文本检测：根据设备性能选择PP-OCRv4_mobile_seal_det或PP-OCRv4_server_seal_det
- 文档图像方向分类：PP-LCNet_x1_0_doc_ori

这种组合在精度和速度之间找到合适的平衡点。
