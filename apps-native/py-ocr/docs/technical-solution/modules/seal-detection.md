# 印章文本检测模块

## 模型选择

### PP-OCRv4系列

- PP-OCRv4_server_seal_det

  - 适用于服务器端部署
  - 更高的检测精度

- PP-OCRv4_mobile_seal_det
  - 适用于移动端部署
  - 更快的推理速度

## 技术原理

### 基础架构

- 基于深度学习算法
- 类似文本检测模块的设计
- 专门针对印章文本特征优化

### 核心功能

1. 特征提取

   - 提取印章文本图像的特征
   - 分析印章中文字的特征模式

2. 位置检测

   - 检测印章中文字的位置
   - 输出文字边界框坐标

3. 模型训练
   - 在自建的印章数据集上训练
   - 识别不同形状、大小和风格的印章文本

## 性能指标

### 检测精度

#### PP-OCRv4_server_seal_det

- 检测Hmean: 98.21%
- CPU推理耗时: 2425.06ms
- GPU推理耗时: 84.341ms

#### PP-OCRv4_mobile_seal_det

- 检测Hmean: 96.47%
- CPU推理耗时: 131.813ms

### 模型存储大小

- PP-OCRv4_mobile_seal_det: 4.6M
- PP-OCRv4_server_seal_det: 109M

## 适用场景

### 高精度需求场景

- 适用模型：PP-OCRv4_server_seal_det
- 应用场景：
  - 合同文件处理
  - 公文识别
  - 证件验证
- 特点：检测精度最高，适合对准确性要求极高的场景

### 移动端场景

- 适用模型：PP-OCRv4_mobile_seal_det
- 应用场景：
  - 移动端文档扫描
  - 实时印章检测
- 特点：推理速度快，模型体积小

## 使用建议

1. 模型选择考虑因素

   - 部署环境（服务器/移动端）
   - 精度要求
   - 响应时间要求
   - 存储空间限制

2. 优化建议

   - 服务器端部署优先考虑PP-OCRv4_server_seal_det
   - 移动端部署选择PP-OCRv4_mobile_seal_det
   - 根据实际需求平衡精度和速度

3. 实际应用建议
   - 注意印章图像的预处理质量
   - 考虑图像分辨率对检测效果的影响
   - 结合业务场景选择合适的后处理策略
