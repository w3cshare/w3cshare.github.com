# 文档图像方向分类模块

## 模型选择

### PP-LCNet模型

- PP-LCNet_x1_0_doc_ori
- 用于对文档图像的方向进行分类
- 支持0度、90度、180度、270度四个方向的分类

## 技术原理

### 基础架构

- 基于深度学习的图像分类算法
- 专门针对文档方向分类优化

### 核心功能

1. 特征提取

   - 提取文档图像的特征
   - 分析图像的方向特征

2. 方向分类

   - 通过分类器判断图像的方向类别
   - 输出四个方向的分类结果

3. 模型训练
   - 使用大量标注了方向的文档图像数据
   - 学习不同方向文档图像的特征模式
   - 提高方向分类的准确性

## 性能指标
