# 整体架构

## 系统架构

文档场景信息抽取项目采用模块化架构，各模块协同工作以实现高效准确的信息抽取。整体架构主要包括以下几个关键部分：

### 数据输入层

- 负责接收各种格式的文档数据，如 PDF、图片等
- 将输入数据转换为适合后续处理的格式

### 预处理层

- 对输入的数据进行预处理操作
- 包括图像增强（如亮度调整、噪声去除等）
- 文档图像方向矫正
- 文本图像矫正等
- 提高后续识别和抽取的准确性

### 核心处理层

由多个模块组成：

- 版面区域检测模块
- 文本检测模块
- 文本识别模块
- 表格结构识别模块
- 印章文本检测模块等
- 分别负责对文档中的不同元素进行检测和识别

### 后处理层

- 对核心处理层的输出结果进行整合和优化
- 将表格识别结果转换为结构化数据格式
- 对提取的文本进行排版整理等

### 输出层

- 将最终抽取的信息以合适的格式输出
- 支持 JSON 格式、Excel 表格等
- 方便用户使用或与其他系统集成

## 上下游服务

### 上游服务

#### 数据来源

- 用户上传的文档文件（PDF、图片等）
- 企业内部数据库中的文档数据
- 网络爬虫获取的相关文档等
- 这些数据通常是未经处理的原始文档，包含各种格式和内容

#### 数据预处理

- 对扫描的纸质文档图像进行图像去噪、增强等操作
- 提高后续处理的准确性

### 下游服务

#### 数据输出

- 结构化数据格式（JSON、Excel表格等）
- 可视化展示（报告、图表等）
- 便于与其他数据库系统或数据分析工具集成

#### 应用场景

- 金融领域：合同审核、风险评估等
- 企业管理：文档管理、数据分析等
- 政府部门：政务信息处理、档案管理等

## 子模块关系

### 数据输入与预处理模块

- 向版面区域检测模块提供预处理后的文档图像
- 为文本图像矫正模块提供待矫正的文本图像
- 将文档图像方向信息传递给文档图像方向分类模块

### 版面区域检测模块

- 为文本检测模块提供文本区域信息
- 帮助表格结构识别模块确定表格区域
- 与印章文本检测模块协作，检测印章区域

### 文本检测模块

- 将检测到的文本区域信息传递给文本识别模块
- 与文本图像矫正模块配合，确保准确检测

### 文本识别模块

- 将识别出的文本信息提供给后处理层
- 与版面区域检测模块协作，进行文本分类和整理

### 表格结构识别模块

- 利用版面区域检测模块提供的表格区域信息
- 将识别出的表格结构信息传递给后处理层

### 印章文本检测模块

- 与版面区域检测模块协作，确定印章区域
- 将检测到的印章文本信息传递给后处理层

### 文本图像矫正模块

- 为文本检测模块和文本识别模块提供矫正后的文本图像

### 文档图像方向分类模块

- 为其他模块提供文档图像的方向信息
- 确保各个模块能够正确处理不同方向的文档图像

### 后处理模块

- 接收来自各个模块的输出结果
- 进行整理和结构化处理
- 将最终处理后的结果输出到下游服务
