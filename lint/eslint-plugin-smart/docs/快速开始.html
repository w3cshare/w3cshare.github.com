快速开始 ​

本文档将帮助您快速上手使用 eslint-plugin-smart 进行代码规范检查。

安装 ​

根据您使用的包管理器选择相应的安装命令：

bash
# 使用 pnpm (推荐)
pnpm add -D eslint eslint-plugin-smart

# 使用 npm
npm install --save-dev eslint eslint-plugin-smart

# 使用 yarn
yarn add --dev eslint eslint-plugin-smart

基础配置 ​

ESLint v9+ ​

如果您使用的是 ESLint v9 及以上版本，请在项目根目录创建 eslint.config.js 文件：

js
export default {
  extends: ['plugin:smart/recommended'],
};
1
2
3

ESLint v8 及以下 ​

如果您使用的是 ESLint v8 及以下版本，请在项目根目录创建 .eslintrc.js 文件：

js
module.exports = {
  extends: ['plugin:smart/recommended'],
};

与编辑器集成 ​

VSCode ​

  1. 安装 ESLint VSCode 插件
  2. 在 VSCode 中创建或编辑 .vscode/settings.json 文件：
json
{
  "editor.codeActionsOnSave": {
    "source.fixAll.eslint": true
  },
  "eslint.validate": [
    "javascript",
    "javascriptreact",
    "typescript",
    "typescriptreact",
    "vue"
  ]
}

WebStorm/IntelliJ IDEA ​

  1. 确保启用了 ESLint 插件（通常默认已启用）
  2. 进入 Settings > Languages & Frameworks > JavaScript > Code Quality Tools > ESLint
  3. 启用 ESLint 并配置适当的设置

在项目中运行 ESLint ​

在 package.json 中添加以下脚本：

json
{
  "scripts": {
    "lint": "eslint . --ext .js,.jsx,.ts,.tsx,.vue",
    "lint:fix": "eslint . --ext .js,.jsx,.ts,.tsx,.vue --fix"
  }
}

与 Git Hooks 集成 ​

我们建议使用 Husky 和 lint-staged 在提交代码前自动运行 ESLint：

bash
# 安装依赖
pnpm add -D husky lint-staged
1
2

在 package.json 中添加以下配置：

json
{
  "scripts": {
    "prepare": "husky install"
  },
  "lint-staged": {
    "*.{js,jsx,ts,tsx,vue}": [
      "eslint --fix"
    ]
  }
}

初始化 Husky：

bash
pnpm run prepare
npx husky add .husky/pre-commit "npx lint-staged"

这样，在每次提交代码前，ESLint 会自动检查并修复您修改的文件中的问题。
