# 规则说明

本文档详细介绍了 eslint-plugin-smart 中包含的规则及其分类。根据项目类型，这些规则被组织成多个预设配置，以便您根据需要进行选择。

## 预设配置

eslint-plugin-smart 提供了以下几种预设配置：

| 预设配置 | 说明 | 适用场景 |
|---------|------|---------|
| `smart/recommended` | 基础推荐配置 | 适用于所有 JavaScript 项目 |
| `smart/typescript` | TypeScript 配置 | 适用于 TypeScript 项目 |
| `smart/react` | React 配置 | 适用于 React 项目 |
| `smart/vue` | Vue 配置 | 适用于 Vue 项目 |
| `smart/nestjs` | NestJS 配置 | 适用于 NestJS 后端项目 |

## 基础规则

以下是 `smart/recommended` 配置中包含的基础规则：

### 代码风格规则

| 规则 | 说明 | 严重级别 |
|-----|------|---------|
| `indent` | 使用一致的缩进（默认为2空格） | 错误 |
| `quotes` | 使用一致的引号风格（默认为单引号） | 错误 |
| `semi` | 要求或禁止使用分号 | 错误 |
| `no-unused-vars` | 禁止出现未使用过的变量 | 警告 |
| `comma-dangle` | 要求或禁止末尾逗号 | 警告 |
| `arrow-parens` | 箭头函数参数括号风格 | 警告 |
| `max-len` | 强制行的最大长度 | 警告 |
| `eol-last` | 要求或禁止文件末尾保留一行空行 | 错误 |

### 代码质量规则

| 规则 | 说明 | 严重级别 |
|-----|------|---------|
| `no-console` | 禁用 console 方法 | 警告 |
| `no-debugger` | 禁用 debugger | 错误 |
| `no-alert` | 禁用 alert、confirm 和 prompt | 错误 |
| `no-eval` | 禁用 eval() | 错误 |
| `no-implied-eval` | 禁止使用类似 eval() 的方法 | 错误 |
| `no-new-func` | 禁止对 Function 对象使用 new 操作符 | 错误 |
| `no-return-assign` | 禁止在 return 语句中使用赋值语句 | 错误 |
| `no-prototype-builtins` | 禁止直接使用 Object.prototypes 的内置属性 | 错误 |
| `curly` | 强制所有控制语句使用一致的括号风格 | 错误 |

### 导入/导出规则

| 规则 | 说明 | 严重级别 |
|-----|------|---------|
| `import/order` | 强制导入的排序 | 警告 |
| `import/first` | 确保所有导入都在文件顶部 | 错误 |
| `import/no-mutable-exports` | 禁止导出可变的绑定 | 错误 |
| `import/no-unresolved` | 确保导入的模块可以被解析 | 错误 |
| `import/no-webpack-loader-syntax` | 禁止在导入中使用 Webpack 加载器语法 | 错误 |

## TypeScript 规则

`smart/typescript` 配置在基础规则基础上增加了对 TypeScript 的支持：

| 规则 | 说明 | 严重级别 |
|-----|------|---------|
| `@typescript-eslint/explicit-function-return-type` | 要求函数和类方法的显式返回类型 | 警告 |
| `@typescript-eslint/explicit-module-boundary-types` | 要求导出函数和类方法的显式返回和参数类型 | 警告 |
| `@typescript-eslint/ban-ts-comment` | 禁止特定类型的注释或要求注释包含描述 | 警告 |
| `@typescript-eslint/no-explicit-any` | 禁止使用 any 类型 | 警告 |
| `@typescript-eslint/no-unused-vars` | 禁止定义未使用的变量 | 错误 |
| `@typescript-eslint/no-non-null-assertion` | 禁止使用非空断言 | 警告 |
| `@typescript-eslint/type-annotation-spacing` | 要求类型注释周围的一致空格 | 错误 |
| `@typescript-eslint/member-delimiter-style` | 要求或禁止在接口和类型字面量中使用分号 | 错误 |

## React 规则

`smart/react` 配置针对 React 项目，包含以下特定规则：

| 规则 | 说明 | 严重级别 |
|-----|------|---------|
| `react/jsx-uses-react` | 防止 React 被标记为未使用 | 错误 |
| `react/jsx-uses-vars` | 防止 JSX 中使用的变量被标记为未使用 | 错误 |
| `react/prop-types` | 验证 props 对象类型的定义 | 警告 |
| `react/react-in-jsx-scope` | 使用 JSX 时防止丢失 React | 错误 |
| `react/jsx-pascal-case` | 强制使用 PascalCase 作为 JSX 组件名 | 错误 |
| `react/jsx-key` | 防止在数组或迭代器中使用的 JSX 缺少 key 属性 | 错误 |
| `react/jsx-no-duplicate-props` | 防止 JSX 中出现重复的 props | 错误 |
| `react/jsx-curly-brace-presence` | 强制使用花括号或不使用花括号 | 警告 |
| `react/jsx-boolean-value` | 在 JSX 中强制布尔属性符号 | 警告 |
| `react/no-array-index-key` | 防止在数组索引处使用 key | 警告 |
| `react/no-direct-mutation-state` | 防止直接修改 this.state | 错误 |
| `react/no-unsafe` | 防止使用不安全的生命周期方法 | 错误 |
| `react-hooks/rules-of-hooks` | 强制 Hook 规则 | 错误 |
| `react-hooks/exhaustive-deps` | 验证依赖关系数组中的依赖 | 警告 |

## Vue 规则

`smart/vue` 配置包含 Vue 项目的专用规则：

| 规则 | 说明 | 严重级别 |
|-----|------|---------|
| `vue/component-name-in-template-casing` | 强制模板中组件名称大小写 | 错误 |
| `vue/html-closing-bracket-newline` | 要求或禁止标签的闭括号前有一个换行 | 错误 |
| `vue/html-closing-bracket-spacing` | 要求或禁止标签的闭括号之前有空格 | 错误 |
| `vue/html-indent` | 强制一致缩进 | 错误 |
| `vue/html-quotes` | 强制 HTML 属性的引号样式 | 错误 |
| `vue/max-attributes-per-line` | 强制每行的最大属性数 | 警告 |
| `vue/multiline-html-element-content-newline` | 要求多行元素的内容前后有一个换行符 | 警告 |
| `vue/mustache-interpolation-spacing` | 强制模板插值的统一间距 | 错误 |
| `vue/no-multi-spaces` | 禁止多个空格 | 错误 |
| `vue/no-template-shadow` | 禁止在模板中声明变量并遮蔽外部作用域中声明的变量 | 错误 |
| `vue/no-unused-components` | 禁止使用未在模板中使用的组件 | 错误 |
| `vue/no-unused-vars` | 禁止模板中未使用的变量 | 错误 |
| `vue/order-in-components` | 强制组件中的属性顺序 | 警告 |

## NestJS 规则

`smart/nestjs` 配置针对 NestJS 后端项目：

| 规则 | 说明 | 严重级别 |
|-----|------|---------|
| `@typescript-eslint/explicit-member-accessibility` | 要求类成员的显式可访问性修饰符 | 错误 |
| `@typescript-eslint/no-useless-constructor` | 禁止不必要的构造函数 | 错误 |
| `@typescript-eslint/explicit-function-return-type` | 要求函数和类方法的显式返回类型 | 错误 |
| `@typescript-eslint/ban-types` | 禁止使用特定类型 | 错误 |
| `@typescript-eslint/no-var-requires` | 禁止使用 var 关键字 | 错误 |
| `@typescript-eslint/interface-name-prefix` | 接口名称不应以 "I" 前缀命名 | 警告 |

## 规则定制

所有规则都可以根据项目需求进行定制。请参考[配置指南](./配置指南.md)了解如何覆盖或扩展默认规则配置。
