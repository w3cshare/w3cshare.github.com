内置插件的使用 ​

如何使用内置插件 ​

eslint-plugin-smart 现在内置了常用的插件，如 eslint-plugin-import、eslint-plugin-simple-import-sort 和 eslint-plugin-unused-imports 等。这意味着你不再需要单独安装这些插件，可以直接通过我们的插件使用它们。

在 ESLint v9+ 中使用 ​

js
// eslint.config.mjs
import eslintPlugin from 'eslint-plugin-smart';

export default [
  // 其他配置...
  {
    plugins: {
      // 直接使用内置插件
      import: eslintPlugin.plugins.import,
      'simple-import-sort': eslintPlugin.plugins['simple-import-sort'],
      'unused-imports': eslintPlugin.plugins['unused-imports'],
    },
    rules: {
      // ...
    },
  },
];

常见问题 ​

问题： 为什么我在配置中使用了内置插件，但仍然报错说找不到插件？

解决： 确保你的 eslint-plugin-smart 是最新版本。此外，检查导入语法是否正确，例如使用 eslintPlugin.plugins['simple-import-sort'] 而不是 eslintPlugin.plugins.simple-import-sort。

问题： 我想使用内置插件的特定规则，但不确定如何配置。

解决： 你可以直接使用插件的规则，就像单独安装这些插件一样：

js
rules: {
  'simple-import-sort/imports': 'error',
  'simple-import-sort/exports': 'error',
  'unused-imports/no-unused-imports': 'error',
}

eslint-config-smart 与 eslint-plugin-smart 混淆问题 ​

问题描述 ​

在使用 ESLint 时，你可能会遇到以下错误：

bash
Error: Cannot find package '/Users/.../node_modules/eslint-config-smart/package.json' imported from ...
1

这个错误通常发生在项目中尝试导入 eslint-config-smart，但该包并不存在或未正确安装。在我们的单体仓库结构中，我们提供的是 eslint-plugin-smart 而非 eslint-config-smart。

解决方案 ​

  1. 修改导入语句：

    将配置文件中的导入语句从：

    js
    import smart from 'eslint-config-smart';
    1

    修改为：

    js
    import smart from 'eslint-plugin-smart';
    1

  2. 更新依赖：

    移除 package.json 中的 eslint-config-smart 依赖，确保正确引用 eslint-plugin-smart：

    json
    "devDependencies": {
  // 移除 "eslint-config-smart": "^1.0.0",
  // 确保有这一行：
  "eslint-plugin-smart": "workspace:^"
}
    1

    3
    4
    5

  3. ESLint 配置文件示例：

    对于 ESLint v9+（使用扁平配置系统）：

    js
    // eslint.config.mjs
import smart from 'eslint-plugin-smart';

export default [
  // 基础配置
  {
    ...smart,
  },
  // 可以在这里添加更多配置对象
];

对于单体仓库项目 ​

在使用 Lerna + Nx + pnpm + Workspace 的单体仓库结构中，建议使用工作空间引用：

json
{
  "dependencies": {
    "eslint-plugin-smart": "workspace:^"
  }
}

不再需要手动安装依赖插件 ​

简化依赖管理 ​

从最新版本开始，eslint-plugin-smart 已经内置了以下常用插件：

  • eslint-plugin-import
  • eslint-plugin-simple-import-sort
  • eslint-plugin-unused-imports
  • @typescript-eslint/eslint-plugin 和 @typescript-eslint/parser（用于TypeScript项目）
  • eslint-plugin-react 和 eslint-plugin-react-hooks（用于React项目）
  • eslint-plugin-jsx-a11y（用于React可访问性）
  • eslint-plugin-vue 和 vue-eslint-parser（用于Vue项目）
  • eslint-plugin-node（用于Node.js和NestJS项目）

这意味着你不再需要在项目的 package.json 中单独列出这些依赖。简化后的依赖看起来像这样：

json
{
  "devDependencies": {
    "eslint": "^9.0.0",
    "eslint-plugin-smart": "workspace:^"
  }
}

常见问题 ​

问题： 我删除了单独的插件依赖，但ESLint报错说找不到插件。

解决： 确保你的ESLint配置正确使用了 eslint-plugin-smart 提供的内置插件，如上面的例子所示。另外，确保使用的是最新版本的 eslint-plugin-smart。

问题： 我需要使用的特定插件不在内置列表中。

解决： 对于不包含在内置列表中的插件，你仍然需要单独安装它们。eslint-plugin-smart 只内置了最常用的插件。
