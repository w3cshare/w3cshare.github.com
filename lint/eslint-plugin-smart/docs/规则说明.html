规则说明 ​

本文档详细介绍了 eslint-plugin-smart 中包含的规则及其分类。根据项目类型，这些规则被组织成多个预设配置，以便您根据需要进行选择。

预设配置 ​

eslint-plugin-smart 提供了以下几种预设配置：

预设配置说明适用场景
smart/recommended基础推荐配置适用于所有 JavaScript 项目
smart/typescriptTypeScript 配置适用于 TypeScript 项目
smart/reactReact 配置适用于 React 项目
smart/vueVue 配置适用于 Vue 项目
smart/nestjsNestJS 配置适用于 NestJS 后端项目

基础规则 ​

以下是 smart/recommended 配置中包含的基础规则：

代码风格规则 ​

规则说明严重级别
indent使用一致的缩进（默认为2空格）错误
quotes使用一致的引号风格（默认为单引号）错误
semi要求或禁止使用分号错误
no-unused-vars禁止出现未使用过的变量警告
comma-dangle要求或禁止末尾逗号警告
arrow-parens箭头函数参数括号风格警告
max-len强制行的最大长度警告
eol-last要求或禁止文件末尾保留一行空行错误

代码质量规则 ​

规则说明严重级别
no-console禁用 console 方法警告
no-debugger禁用 debugger错误
no-alert禁用 alert、confirm 和 prompt错误
no-eval禁用 eval()错误
no-implied-eval禁止使用类似 eval() 的方法错误
no-new-func禁止对 Function 对象使用 new 操作符错误
no-return-assign禁止在 return 语句中使用赋值语句错误
no-prototype-builtins禁止直接使用 Object.prototypes 的内置属性错误
curly强制所有控制语句使用一致的括号风格错误

导入/导出规则 ​

规则说明严重级别
import/order强制导入的排序警告
import/first确保所有导入都在文件顶部错误
import/no-mutable-exports禁止导出可变的绑定错误
import/no-unresolved确保导入的模块可以被解析错误
import/no-webpack-loader-syntax禁止在导入中使用 Webpack 加载器语法错误

TypeScript 规则 ​

smart/typescript 配置在基础规则基础上增加了对 TypeScript 的支持：

规则说明严重级别
@typescript-eslint/explicit-function-return-type要求函数和类方法的显式返回类型警告
@typescript-eslint/explicit-module-boundary-types要求导出函数和类方法的显式返回和参数类型警告
@typescript-eslint/ban-ts-comment禁止特定类型的注释或要求注释包含描述警告
@typescript-eslint/no-explicit-any禁止使用 any 类型警告
@typescript-eslint/no-unused-vars禁止定义未使用的变量错误
@typescript-eslint/no-non-null-assertion禁止使用非空断言警告
@typescript-eslint/type-annotation-spacing要求类型注释周围的一致空格错误
@typescript-eslint/member-delimiter-style要求或禁止在接口和类型字面量中使用分号错误

React 规则 ​

smart/react 配置针对 React 项目，包含以下特定规则：

规则说明严重级别
react/jsx-uses-react防止 React 被标记为未使用错误
react/jsx-uses-vars防止 JSX 中使用的变量被标记为未使用错误
react/prop-types验证 props 对象类型的定义警告
react/react-in-jsx-scope使用 JSX 时防止丢失 React错误
react/jsx-pascal-case强制使用 PascalCase 作为 JSX 组件名错误
react/jsx-key防止在数组或迭代器中使用的 JSX 缺少 key 属性错误
react/jsx-no-duplicate-props防止 JSX 中出现重复的 props错误
react/jsx-curly-brace-presence强制使用花括号或不使用花括号警告
react/jsx-boolean-value在 JSX 中强制布尔属性符号警告
react/no-array-index-key防止在数组索引处使用 key警告
react/no-direct-mutation-state防止直接修改 this.state错误
react/no-unsafe防止使用不安全的生命周期方法错误
react-hooks/rules-of-hooks强制 Hook 规则错误
react-hooks/exhaustive-deps验证依赖关系数组中的依赖警告

Vue 规则 ​

smart/vue 配置包含 Vue 项目的专用规则：

规则说明严重级别
vue/component-name-in-template-casing强制模板中组件名称大小写错误
vue/html-closing-bracket-newline要求或禁止标签的闭括号前有一个换行错误
vue/html-closing-bracket-spacing要求或禁止标签的闭括号之前有空格错误
vue/html-indent强制一致缩进错误
vue/html-quotes强制 HTML 属性的引号样式错误
vue/max-attributes-per-line强制每行的最大属性数警告
vue/multiline-html-element-content-newline要求多行元素的内容前后有一个换行符警告
vue/mustache-interpolation-spacing强制模板插值的统一间距错误
vue/no-multi-spaces禁止多个空格错误
vue/no-template-shadow禁止在模板中声明变量并遮蔽外部作用域中声明的变量错误
vue/no-unused-components禁止使用未在模板中使用的组件错误
vue/no-unused-vars禁止模板中未使用的变量错误
vue/order-in-components强制组件中的属性顺序警告

NestJS 规则 ​

smart/nestjs 配置针对 NestJS 后端项目：

规则说明严重级别
@typescript-eslint/explicit-member-accessibility要求类成员的显式可访问性修饰符错误
@typescript-eslint/no-useless-constructor禁止不必要的构造函数错误
@typescript-eslint/explicit-function-return-type要求函数和类方法的显式返回类型错误
@typescript-eslint/ban-types禁止使用特定类型错误
@typescript-eslint/no-var-requires禁止使用 var 关键字错误
@typescript-eslint/interface-name-prefix接口名称不应以 "I" 前缀命名警告

规则定制 ​

所有规则都可以根据项目需求进行定制。请参考配置指南了解如何覆盖或扩展默认规则配置。
