ESLint 代码质量规则详解 ​

本文档详细介绍了 eslint-plugin-smart 插件中的各类代码质量规则，并提供了错误示例和正确用法示例，帮助开发者更好地理解和应用这些规则。

JavaScript 基础规则 ​

规则名称支持自动修复描述
no-var✅禁止使用 var 声明变量
no-console❌生产环境下禁止使用 console
no-debugger❌生产环境下禁止使用 debugger
no-alert❌生产环境下禁止使用 alert、confirm 或 prompt
no-unexpected-multiline❌禁止出现令人困惑的多行表达式
no-nested-ternary❌禁止使用嵌套的三目运算符
consistent-return❌要求函数要么始终有返回值，要么始终没有返回值
no-cond-assign❌禁止在条件语句中使用赋值操作符
no-use-before-define❌禁止在变量和类定义之前使用它们
require-yield❌禁用函数内没有yield的 generator 函数
eqeqeq✅要求使用 === 和 !== 进行比较
prefer-const✅声明后不再被修改的变量必须使用 const
no-const-assign❌禁止修改 const 声明的变量

no-var ​

支持自动修复 ✅

禁止使用 var 声明变量，应使用 let 或 const

javascript
// 🔴 错误的用法
var foo = 'bar';

// ✅ 正确的用法
const foo = 'bar';
let bar = 'baz';

complexity ​

不支持自动修复 ❌

圈复杂度不超过10

javascript
// 🔴 错误的用法 - 圈复杂度过高
function doSomething() {
  if (cond1) { /* ... */ }
  else if (cond2) { /* ... */ }
  else if (cond3) { /* ... */ }
  else if (cond4) { /* ... */ }
  else if (cond5) { /* ... */ }
  
  for (let i = 0; i < 10; i++) {
    if (arr[i] > 5) { /* ... */ }
    else { /* ... */ }
  }
  
  switch (value) {
    case 1: /* ... */ break;
    case 2: /* ... */ break;
    case 3: /* ... */ break;
    default: /* ... */
  }
}

// ✅ 正确的用法 - 拆分为多个函数，降低复杂度
function handleConditions() {
  if (cond1) return result1;
  if (cond2) return result2;
  if (cond3) return result3;
  return defaultResult;
}

function processArray(arr) {
  return arr.map(item => item > 5 ? doThis() : doThat());
}

function doSomething() {
  const result1 = handleConditions();
  const result2 = processArray(someArray);
  return combineResults(result1, result2);
}
