# eslint-plugin-smart 快速开始

::: tip 插件介绍
eslint-plugin-smart 是一个为公司内部项目设计的 ESLint 规则集合，提供了针对 JavaScript、TypeScript、React、Vue 和 Node.js 等多种技术栈的全面规则配置。插件采用模块化设计，便于维护和扩展。
:::

## 快速开始

### 安装

根据您使用的包管理器选择相应的安装命令：

::: code-group

```bash [pnpm]
# 使用 pnpm (推荐)
pnpm add -D eslint eslint-plugin-smart
```

```bash [npm]
# 使用 npm
npm install --save-dev eslint eslint-plugin-smart
```

```bash [yarn]
# 使用 yarn
yarn add --dev eslint eslint-plugin-smart
```

:::

### 基础配置

::: code-group

```js [ESLint v9+ (扁平配置)]
// eslint.config.mjs
import eslintPlugin from 'eslint-plugin-smart';

// 注意：配置是一个数组，需要展开
export default [
  ...eslintPlugin.configs.recommended,
  {
    // 这里可以添加自定义规则
  },
];
```

```js [ESLint v8 及以下]
// .eslintrc.js
module.exports = {
  extends: ['plugin:smart/recommended'],
};
```

:::

## 规则说明

eslint-plugin-smart 采用模块化设计，提供了多种预设配置，根据项目类型可选择不同的配置集合：

| 预设配置           | 说明                  | 适用场景                    |
| ------------------ | --------------------- | --------------------------- |
| `smart/base`       | 基础 JavaScript 配置  | 适用于所有 JavaScript 项目  |
| `smart/typescript` | TypeScript 配置       | 适用于 TypeScript 项目      |
| `smart/react`      | React 配置            | 适用于 React 项目           |
| `smart/vue`        | Vue 配置              | 适用于 Vue 项目             |
| `smart/nodejs`     | Node.js 配置          | 适用于 Node.js 后端项目     |
| `smart/recommended`| 全栈推荐配置          | 适用于全栈开发项目          |

### 模块化设计

eslint-plugin-smart 将各技术栈的规则集分离出来，便于维护和扩展：

```js
// 分别导出各个技术栈的规则集
export const javascriptRules = { /* JavaScript 规则 */ };
export const typescriptRules = { /* TypeScript 规则 */ };
export const reactRules = { /* React 规则 */ };
export const vueRules = { /* Vue 规则 */ };
export const nodejsRules = { /* Node.js 规则 */ };

// 组合规则集
export default {
  base: javascriptRules,
  typescript: { ...javascriptRules, ...typescriptRules },
  react: { ...javascriptRules, ...reactRules },
  vue: { ...javascriptRules, ...vueRules },
  nodejs: { ...javascriptRules, ...nodejsRules },
  recommended: {
    ...javascriptRules,
    ...typescriptRules,
    ...reactRules,
    ...vueRules,
    ...nodejsRules,
  },
};
```

### 基础 JavaScript 规则

以下是 `smart/base` 配置中包含的部分基础规则：

::: details 代码风格规则
| 规则 | 说明 | 严重级别 |
|-----|------|---------|
| `indent` | 使用一致的缩进（默认为2空格） | 错误 |
| `quotes` | 使用一致的引号风格（默认为单引号） | 错误 |
| `semi` | 要求或禁止使用分号（默认禁止） | 错误 |
| `no-unused-vars` | 禁止出现未使用过的变量 | 错误 |
| `comma-dangle` | 要求或禁止末尾逗号（多行时要求） | 错误 |
| `space-before-function-paren` | 函数括号前的空格风格 | 错误 |
| `eol-last` | 要求或禁止文件末尾保留一行空行 | 错误 |
:::

::: details 代码质量规则
| 规则 | 说明 | 严重级别 |
|-----|------|---------|
| `no-console` | 生产环境禁用 console | 警告 |
| `no-debugger` | 生产环境禁用 debugger | 错误 |
| `no-alert` | 生产环境禁用 alert、confirm 和 prompt | 错误 |
| `no-var` | 要求使用 let 或 const 而不是 var | 错误 |
| `prefer-const` | 声明后未被修改的变量必须使用 const | 错误 |
| `no-eval` | 禁用 eval() | 错误 |
| `no-implied-eval` | 禁止使用类似 eval() 的方法 | 错误 |
| `no-new-func` | 禁止对 Function 对象使用 new 操作符 | 错误 |
| `eqeqeq` | 要求使用 === 和 !== | 错误 |
| `complexity` | 限制代码的圈复杂度不超过10 | 警告 |
:::

::: details 导入/导出规则
| 规则 | 说明 | 严重级别 |
|-----|------|---------|
| `simple-import-sort/imports` | 强制导入的排序，更智能 | 错误 |
| `simple-import-sort/exports` | 强制导出的排序 | 错误 |
| `unused-vars-and-imports/no-unused-imports` | 禁止未使用的导入 | 错误 |
| `unused-vars-and-imports/no-unused-vars` | 禁止未使用的变量 | 错误 |
:::

## 自定义配置

你可以在项目中扩展基础配置并添加自定义规则：

::: code-group

```js [ESLint v9+]
// eslint.config.mjs
import eslintPlugin from 'eslint-plugin-smart';

export default [
  ...eslintPlugin.configs.typescript, // 使用 TypeScript 预设
  {
    // 覆盖或添加自定义规则
    rules: {
      // 关闭部分规则
      '@typescript-eslint/no-explicit-any': 'off',
      'no-console': 'off',
      
      // 调整规则设置
      'max-len': ['warn', { code: 100, ignoreComments: true }],
      
      // 添加自定义规则
      'prefer-template': 'error',
    }
  }
];
```

```js [ESLint v8 及以下]
// .eslintrc.js
module.exports = {
  extends: ['plugin:smart/typescript'], // 使用 TypeScript 预设
  rules: {
    // 关闭部分规则
    '@typescript-eslint/no-explicit-any': 'off',
    'no-console': 'off',
    
    // 调整规则设置
    'max-len': ['warn', { code: 100, ignoreComments: true }],
    
    // 添加自定义规则
    'prefer-template': 'error',
  }
};
```

:::
