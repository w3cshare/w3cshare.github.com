# Micro App VAP 文档优化提示词

## 对话内容

### 用户提问
根据项目目录结构，优化 VitePress 文档输出。

### AI 回答
1. 创建了 VitePress 配置文件 `.vitepress/config.ts`，设置了：
   - 导航栏配置
   - 侧边栏结构
   - 主题配置
   - 多语言支持

2. 创建了文档主页 `index.md`，包含：
   - Hero 部分展示项目名称和简介
   - Features 部分展示核心特性
   - 快速开始和 GitHub 链接

3. 创建了项目结构文档 `guide/project-structure.md`，详细说明：
   - 完整的目录树结构
   - 各目录的用途说明
   - 配置文件说明
