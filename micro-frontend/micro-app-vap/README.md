# Micro App VAP

> 参考文档：https://github.com/ant-design/ant-design-pro-layout

基于 Vue3 + Ant Design + Pinia 的微前端应用。

## 🚀 特性

- 📦 基于 Vue3 + TypeScript 开发
- 🎨 集成 Ant Design Vue 组件库
- 📱 响应式设计，支持多端适配
- 🔑 内置权限管理系统
- 🌐 支持国际化
- 🔧 完善的开发工具链

## 📚 文档

我们使用 VitePress 构建了完整的项目文档，包括：

- 快速开始指南
- 项目结构说明
- 组件文档
- API 参考
- 最佳实践

访问 [在线文档](https://your-domain.com/docs) 了解更多信息。

### 本地运行文档

```bash
# 安装依赖
pnpm install

# 启动文档开发服务器
pnpm docs:dev

# 构建文档
pnpm docs:build
```

## 🛠️ 开发

```bash
# 安装依赖
pnpm install

# 启动开发服务器
pnpm dev

# 构建生产版本
pnpm build

# 运行测试
pnpm test
```

## 📂 项目结构

```bash
micro-app-vap/
├── config/              # 项目配置文件
├── docs/               # 项目文档
├── mock/               # 模拟数据
├── public/             # 静态资源
├── src/                # 源代码
│   ├── assets/         # 资源文件
│   ├── components/     # 公共组件
│   ├── pages/          # 页面组件
│   └── stores/         # 状态管理
└── tests/              # 测试文件
```
